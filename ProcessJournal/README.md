# Journal entry week 4

# This week, we assigned some tasks to start narrowing down our project more. We decided that a good way to merge all our ideas was to create a node based game editor where the user can pick from 3 base games. After picking from pong, chess or the snake game, the player can edit nodes and sliders that control various parameters in that particular game(for example, in pong you would be able to edit the ball size and speed). The player can then test out their small variation. This seemed to be a good way to make a straightforward software function as both a game and a game editor. We were not able to get further feedback from our client, so for the time being we are running with this idea. With the basic concept decided, we each did our tasks for the week. Everyone was encouraged to add to the mood board, and Hanif and I were assigned the wireframe. After Nat finished figuring out the user flow diagram, we started with the wireframe. I was working on one in Balsamiq, but Hanif created one in our Figma project which was more immediately accessible. Because we had spoken earlier about a slightly wacky and surreal visual language for the project,  I added images from bizarre 90s games that I thought could be interesting visual inspiration in the moodboard, such as LSD Dream Emulator. These images were somewhat aligned with what Julia and Olivia added to the moodboard as well as the coloured sketches they created. These ideas and images made us think that a fitting addition to the game editor would be a ‘Clippy’ style virtual assistant. All the weekly tasks were completed.
